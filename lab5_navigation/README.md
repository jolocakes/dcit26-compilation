# lab5_navigation

This application uses Flutter's root Navigator to manage the Home, Profile, and About screens. The Navigator.push method with MaterialPageRoute is used to open new screens, while Navigator.pop is used to return to previous screens. The Drawer provides navigation access to Home and About.
